# 乐谱反复段展开工具

供排练使用的 Web 应用：逐行输入小节编号与反复记号，自动校验并展开为实际演奏顺序，
同时按拍数与速度（BPM）累计排练时间轴。页面展示演奏序号、原小节编号、源行号与
每次经过的起止时间（毫秒），并可下载同内容的 CSV。

## 启动

```bash
docker compose up --build
```

容器启动时会自动安装依赖（`pip install -r requirements.txt`）并启动应用。

## 访问

浏览器打开 <http://localhost:5000>

## 配置

| 环境变量 | 默认值 | 说明 |
| -------- | ------ | ---- |
| `PORT`   | `5000` | 应用监听端口（修改后请同步调整 compose 的端口映射） |

## 输入格式

每行一个小节编号：

- 编号前加 `|:` 表示反复起点
- 编号后加 `:|xN` 表示反复终点，`N` 为重复次数（2~9）
- 反复段允许嵌套；空行会被忽略
- 行末（所有反复记号之后）可附 `[拍数]` 或 `[拍数@BPM]`：
  - 拍数为正整数，默认 4
  - BPM 为正整数；初始速度为 120，未标速度的小节沿用上一演奏小节的速度

示例：

```
1
2
|:3
4
|:5
6:|x3
7:|x2
8
```

展开结果：`1 2 3 4 5 6 5 6 5 6 7 3 4 5 6 5 6 5 6 7 8`（共 21 小节）。

## 排练时间轴

带速度标记的小节每次在实际演奏顺序中出现时，都先切换速度，再按

```
时长（毫秒）= 拍数 × 60000 / BPM
```

累计；未标速度则沿用上一演奏小节的速度。累计过程保留浮点精度，输出的起止时间
四舍五入到最近毫秒。

带时间标记的示例：

```
1
2[3]
|:3[4@60]
4
|:5
6:|x3
7:|x2
8[2@240]
```

展开顺序仍为 21 小节，前三次经过的时间为：

| 演奏序号 | 原小节 | 速度 BPM | 起（毫秒） | 止（毫秒） |
| -------- | ------ | -------- | ---------- | ---------- |
| 1 | 1 | 120 | 0 | 2000 |
| 2 | 2 | 120 | 2000 | 3500 |
| 3 | 3 | 60 | 3500 | 7500 |

第 3 小节标记了 `[4@60]`，因此反复段内每次演奏到它都会切换回 60 BPM；
第 8 小节以 240 BPM 演奏 2 拍，全曲总时长 76000 毫秒。

## 校验规则

- 格式错误：定位到具体输入行
- 小节编号必须唯一，重复时指出首次出现的行号
- `|:` 与 `:|xN` 必须配对，未配对时定位到对应行
- 拍数与 BPM 必须为正整数，错误定位到源行
- 展开超过 5000 小节时停止，并指出导致超限的源行

## 本地开发（不使用 Docker）

```bash
pip install -r requirements.txt
python app.py
```

## 项目结构

```
app.py               Flask 应用与 API
repeats.py           反复段解析、校验与展开逻辑

requirements.txt     Python 依赖
Dockerfile           镜像构建（依赖随容器启动安装）
docker-compose.yml   Compose 编排
```
